## 范式目标

* 以 30–60 分钟内完成“学习仓库初始化 + 联调环境 + 文档站点”的最小闭环

* 标准化章节结构、分析路径与验证步骤，支持快速迁移到任意三方库/开源项目

* 统一发布到 GitHub Pages 的项目子目录，保持版本同步与可视追踪

## 仓库与分支

* 初始化

  * 先在 GitHub 上 fork 上游仓库；将本地 `origin` 指向你的 fork，创建 `learning` 分支，并添加 `upstream` 指向上游仓库（用于后续同步）

  ```bash
  # 如果最初克隆的是上游仓库，先把 origin 改为你的 fork
  git remote set-url origin git@github.com:<your-account>/<repo>.git

  # 创建学习分支
  git checkout -b learning

  # 添加 upstream 指向上游仓库
  git remote add upstream git@github.com:<upstream-org>/<repo>.git
  ```

* 目录结构（可直接复用）

  * `packages/playground`：联调环境（Vite + Vue/React + TS）

  * `docs/`：VitePress 文档站点（`guide/01–12` 分章）

* 同步策略

  * 定期同步上游：

  ```bash
  # 拉取上游更新并合并到本地学习分支
  git fetch upstream
  git merge upstream/main   # 或 upstream/develop / upstream/learning，视上游分支策略而定

  # 推送到你的 fork
  git push origin learning
  ```

## 联调环境（Playground 模板）

* 目的：直连源码、快速验证组件样式与交互

* 要点

  * `vite.config.ts` 别名 → 源码目录（如 `tdesign-vue-next`、`@tdesign/components`、`@tdesign/common-style`）

  * 样式入口：`@library/components/style/index.js` + `@library/common-style/*`

  * TS 路径与类型：`tsconfig.json` 的 `baseUrl/paths`；`src/env.d.ts` 声明 `*.vue/tsx`

* 最小脚本

  * `pnpm -C packages/playground dev`

## 文档站点（VitePress 模板）

* 配置

  * `docs/.vitepress/config.ts`：`lang/title/description/lastUpdated`，`nav: [{ text: '指南', link: '/guide/' }]`

  * `sidebar`：映射 12 章节（全部 `collapsed:false`，默认展开）

  * 主题：`docs/.vitepress/theme/index.ts` 导入默认主题 + `custom.css`（品牌色变量：`--vp-c-brand-1/2/3`）

* 首页（`docs/index.md`）

  * `layout: home`；`hero` + `features`（12 章节卡片）；`todo` 清单（勾选已完成项）

* 运行脚本

  * `docs:dev`、`docs:build`、`docs:preview`

## 章节范式（可复制到任何源码）

* 01 总览：项目结构、工作区与脚本

* 02 运行与构建：安装、开发、构建、覆盖率、Playground（强制准备）

* 03 组件/模块架构：目录、文件约定、Props/配置、事件、插槽/扩展点、Hooks/工具、注册/装配

* 04 样式与主题：CSS 变量/Token、主题切换、覆盖策略、样式入口

* 05 国际化：资源位置、全局配置注入、组件级覆盖

* 06 测试方案：单测（渲染/交互）、快照（SSR/CSR）、覆盖率

* 07 文档与示例：Markdown 解析管线、示例容器语法、示例位置

* 08 构建与发布：打包产物/策略、站点构建、Babel/PostCSS、Changelog/发布

* 10 规范与流程：ESLint/Prettier、提交规范、PR 审核、CI 工作流

* 11 路径速查：核心路径清单

* 12 代码参考：关键函数与行号（`file_path:line_number`）

## 分析与记录范式（每次学习遵循）

* 入口梳理：总览 → 构建 → 组件/模块入口 → 文档/示例 → 测试

* 组件/模块要点（统一模板）

  * 文件角色：`*.tsx|*.ts` 主实现、`props|type`、`index`、`style`、`tests`、`examples`

  * Props 设计：必填/可选、类型与默认值、枚举与校验

  * 事件机制：`onXxx` 函数型 prop 或 `emits`；参数结构与触发点

  * 插槽/扩展点：默认/命名/作用域插槽；扩展钩子

  * 样式系统：变量、类名前缀、状态类、主题适配

  * 国际化：全局/局部覆盖；`useConfig`/`t`

  * 测试：渲染/交互/快照；覆盖率指标

  * 构建与导出：多产物布局与 sideEffects（样式）

* 记录规范

  * 页面结构：目标/关键路径/操作步骤/验证

  * 代码引用：`file_path:line_number`

  * Lint：遵循 Markdownlint（如 MD032 列表空行）

## 实践与验证范式

* 对照重写（Button/Input/Select 类）

  * 目标/路径/实现步骤/验收标准（行为一致、插槽一致、可访问性、测试通过）

* 修改与扩展

  * 新增 prop/交互；文档与示例补齐；单测与快照回归

* 新组件模板

  * 使用脚手板生成目录；完善 `props|type|index|style|docs|examples|tests`
